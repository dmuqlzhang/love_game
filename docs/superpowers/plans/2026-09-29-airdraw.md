# 隔空画符 Implementation Plan

> **For agentic workers:** Use superpowers:subagent-driven-development for the independent gesture engine and review; implement browser integration in this session. Steps use checkboxes.

**Goal:** 本地浏览器中完成手部骨架、食指画线、捏合拖动、发光粒子、防抖、清空，以及无摄像头的鼠标试用。

**Architecture:** 原生 ES modules + Canvas 2D，交互引擎不依赖 DOM；摄像头控制器通过 Worker 调用 MediaPipe。静态模型、WASM 和 JS 在安装时复制到 public，运行时只访问 localhost。

**Tech Stack:** Node.js 22、Vite、@mediapipe/tasks-vision、Node 内置 test。

项目是空目录且没有 Git 仓库，不创建额外 worktree 或强行提交。

## 文件职责

- `src/core.js`：手势分类、平滑、绘制/拖动状态和几何命中。
- `tests/core.test.js`：独立于摄像头的状态转换和几何测试。
- `src/renderer.js`：霓虹笔迹、粒子、手骨架及指尖渲染。
- `src/camera.js`、`public/hand-worker.js`：摄像头生命周期、单帧背压、模型推理、错误回传。
- `src/main.js`、`src/style.css`、`index.html`：中文界面、键盘/鼠标/手势输入和可访问状态。
- `scripts/setup-assets.mjs`、`package.json`：固定依赖、准备本地模型及启动构建命令。
- `README.md`、`启动.command`、`启动.bat`：运行与故障排查。
