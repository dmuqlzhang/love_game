# 灵绘 · 隔空创作实验室

根据参考视频独立实现的本地浏览器手势画布，包含可配置收礼人姓名的“星光花束”和原有“自由画布”两种模式。普通摄像头即可尝试，也可以用按钮、键盘与鼠标完成整场表演。

## Windows 免安装版

发布后可在 GitHub Releases 下载 LingHui-版本号-win-x64.exe，放在可写文件夹中双击运行，无需安装 Node.js、浏览器依赖或另行下载手部模型。目标架构为 Windows x64。首次启动需解压内部运行时，可能比后续启动慢。

程序首次启动会在 exe 旁边生成 config.json，桌面版默认姓名为“亲爱的”。通过菜单“配置 → 修改姓名配置”编辑 recipientName，保存后按 Ctrl+R 刷新；刷新会清空当前表演。已有配置不会被升级覆盖。换目录或分享给别人时，可同时复制 exe 与 config.json；只复制 exe 会在新目录生成默认配置。

页面右上角的全屏按钮仍只显示画布，Esc 退出。模型与音效均在本机运行。桌面窗口只允许本应用的摄像头视频权限，不申请麦克风。程序关闭时本地临时端口服务同时关闭。

当前打包配置未配置代码签名证书，Windows 可能显示“未知发布者”或 SmartScreen 提示。公开分发时可以后续接入正式签名证书；本项目不会自动生成受信任的发布者身份。

## 源码启动

需要 Node.js 22.12+。使用浏览器版时推荐 Chrome / Edge。首次安装需要联网下载 npm 依赖、Electron 运行时和 Google 官方手部模型；exe 使用者不需要安装这些开发工具。

```sh
npm install
npm run setup
npm run dev
```

打开终端显示的本地地址，默认是 <http://127.0.0.1:5173/>。后续资源已准备好时只需 `npm run dev`。

Mac 可双击 `启动.command`；Windows 可双击 `启动.bat`。如果系统无法找到 Node，请先安装 Node.js 并重新打开终端。启动脚本不会自动安装软件。

不要直接双击 `index.html`：摄像头和 Worker 需要通过 localhost 或 HTTPS 提供页面。

## 配置姓名

编辑项目中的 public/config.json，修改 recipientName（保留英文双引号）：

```json
{
  "recipientName": "李舒曼"
}
```

保存后刷新页面即可，无需重启服务。页面标题、顶部名字、爱心中的名字、告白全文与烟花提示会使用同一姓名；告白正文保持不变。姓名首尾空格会自动去除，较长姓名会在爱心内缩放显示。刷新会清空本次表演，建议在开始前修改。

配置文件缺失、JSON 格式错误或姓名为空／不是字符串时，页面会显示提示，并暂用“亲爱的”。修正文件后刷新即可恢复。

运行 npm run build 后，配置会复制到 dist/config.json；部署构建产物时，直接修改该文件并刷新即可，无需重新构建。再次构建会以 public/config.json 覆盖它，请将希望长期保留的姓名同步保存到源配置。

## 星光花束

页面默认进入浪漫模式。建议先用按钮排练，再开启摄像头；一次只跟踪一只手。

| 手势 | 效果 | 按钮 / 快捷键 |
| --- | --- | --- |
| 比 V 并保持约 0.6 秒 | 点亮两颗金色星星 | 点亮星星 / `1` |
| 张开手掌并保持约 0.6 秒 | 开出一朵粉色花 | 掌心开花 / `2` |
| 在星花附近捏合拇指和食指 | 抓住并移动，松手放下 | 鼠标按住星花拖动 |
| 握拳并保持约 0.6 秒 | 星花汇聚成一颗爱心，约 2.2 秒完成 | 汇聚成心 / `3` |
| 爱心完成后再次张掌 | 先出现名字，再逐字浮现告白 | 送出告白 / `4` |
| 🤟 拇指、食指、小指伸出，中指与无名指收起，保持约 0.6 秒 | 漫天烟花与绽放音效 | 漫天烟花 / `5` |
| — | 清空本次星光，重新表演 | 重新开始 / `R` |

> 李舒曼，今晚的星光送给你，往后每一个平凡的日子，我都想和你一起。

同一手势持续保持只触发一次；换成其他手势约 0.25 秒后才能再次触发。若汇聚期间已张掌，请先收手再张开，避免提前显示告白。星花不足时汇聚会自动补足到 32 个，最多保留 64 个。系统开启“减少动态效果”时，汇聚缩短为 0.15 秒，文字直接显示。

烟花可在浪漫模式任意阶段播放，也可以在告白后作为收尾：彩色圆花、爱心烟花和金色垂柳分批升空绽放，每场约 9 秒，播放中不叠加。建议点右上角“全屏画布”再表演：全屏仅显示画布，隐藏按钮和状态提示；手势与数字键 1–5、R 仍可使用，按 Esc 退出后恢复控制界面。切换模式、重新开始或页面进入后台时，烟花与声音立即停止。减少动态效果下显示少量淡入淡出的静态烟花。

声音由浏览器 Web Audio 本地合成，包含升空、爆裂与余响，不下载音频、不请求麦克风。首次点击页面按钮或按表演快捷键后解锁音频；也可单独点“开启音效”。默认音量 35%，支持静音与音量调节。浏览器禁止播放或音频设备不可用时，烟花画面仍可运行。PNG 只保存当前画面，不包含声音或动画。

可关闭手部骨架与摄像头背景，让最终星光画面更干净；点击右上角保存按钮可导出 PNG。场景坐标使用画布中央正方形，星花拖动范围限制在其中，以保持爱心比例。切换两种模式保留各自内容，但刷新或关闭页面会清空。

## 自由画布

点击页面上方“自由画布”切换到原有功能。

1. 点击“开启摄像头”，在浏览器允许摄像头访问。只请求视频，不请求麦克风。若内置浏览器不支持摄像头，请复制本地地址到 Chrome / Edge。
2. 手掌完整入镜，伸出食指、收起其余手指，移动食指绘制；改变手势暂停落笔。
3. 多笔画会组成当前图形。按 Enter 或点“完成图形”结束分组；开始捏合抓取也会自动结束当前分组。
4. 在笔迹附近捏合拇指和食指，选中图形变黄，保持捏合移动，松开后放下。不支持从远处捏合后扫过来抓取，应先靠近再捏合。
5. 关闭摄像头后可用鼠标：左键画线，V 切换移动，D 切回画笔，Enter 完成图形，Ctrl/Cmd+Z 撤销上一笔，C 清空。

右侧可切换骨架、摄像头背景、镜像，以及指尖防抖强度；防抖对两种模式都生效，更强可能增加跟随延迟。点击保存按钮下载当前画布 PNG；若开启摄像头背景，保存的图片也包含该画面。

页面中的初始星星与骨架是**示例图案**，开始创作即清除。当前画布只保存在内存，刷新或关页会清空；需要保留时先保存 PNG。页面切到后台会自动关闭摄像头。

## 打包 Windows exe

首次在源码目录运行 npm ci，然后运行：

```sh
npm test
npm run dist:win
```

输出位于 release/LingHui-1.0.2-win-x64.exe（文件名跟随 package.json 版本），同时生成 SHA256SUMS.txt 和 package-report.json。打包会自动准备本地模型、构建网页、使用中性姓名生成桌面资源，再检查 exe 格式、x64 架构和归档中每个页面／模型资源的 SHA-256。无需将 node_modules、dist、release 或模型二进制提交到 Git。

npm run desktop 可启动本机桌面开发版；npm run desktop:smoke 会在隐藏窗口验证姓名配置、画布初始化、摄像头安全上下文，并使用真实模型推理一张空白帧，不申请摄像头。Windows 上可以运行 scripts/smoke-windows.ps1 验证生成的 exe；此检查不会替代真人摄像头、全屏操作和声音试听。

## Mac 安装与打包

GitHub Release 提供两种 Mac 版本：M 系列芯片下载 mac-arm64，Intel 芯片下载 mac-x64。推荐下载 DMG，打开后将“灵绘.app”拖入“应用程序”；ZIP 解压后也可将应用拖入“应用程序”。需要 macOS 12 或更新版本。

当前使用临时签名（ad-hoc），没有 Apple Developer ID 签名或 Apple 公证。首次运行可能被 Gatekeeper 拦截；确认下载来自本仓库后，可在“系统设置 → 隐私与安全性”允许打开。无需关闭系统安全功能。摄像头权限仅在用户开启摄像头时申请；可在系统隐私设置中管理。

Mac 姓名配置在 `~/Library/Application Support/灵绘/config.json`，可通过应用菜单“配置 → 修改姓名配置…”打开，保存后按 Cmd+R 刷新。

在 Mac 源码目录运行（Intel 将 arm64 换为 x64）：

```sh
npm ci
npm run dist:mac -- --arm64
npm run verify:mac -- arm64
npm run smoke:mac -- arm64
```

产物为 `release/LingHui-1.0.2-mac-arm64.dmg` 和 `.zip`。验证包括 Mac 可执行架构、资源哈希、摄像头用途说明、临时签名、DMG 完整性，以及解压发布 ZIP 后实际启动应用进行模型推理。Intel CI 虚拟机的默认图形后端不可用，启动检查显式使用 OpenGL 后端；普通用户启动不带此参数。

## GitHub 自动构建与 Release

配置在 .github/workflows/windows-release.yml。将源码和 package-lock.json 推送到自己的 GitHub 仓库并启用 Actions 后：

- 普通分支推送、Pull Request、手动运行：Windows、Apple 芯片 Mac 和 Intel Mac runner 分别测试、打包并运行应用自检；通过后在 Actions Artifacts 中提供各平台安装包，保留 14 天。
- 推送 v 开头的版本标签：标签必须与 package.json 的版本完全一致；全部检查通过后，自动创建 Release 并上传 Windows exe、两种 Mac 架构的 DMG/ZIP 和汇总 SHA256SUMS.txt。含连字符的预发布版本会标为 Pre-release。
- 发布使用仓库自带的 GITHUB_TOKEN，仅发布 job 申请 contents: write，不需要将个人访问令牌写进源码。
- 已公开发布的同名 Release 不会被覆盖；失败留下的草稿可以重新运行工作流补齐并发布。

当前版本是 1.0.2。先将本次代码提交并推送到自己的仓库，再发布首个版本：

```sh
git tag v1.0.2
git push origin v1.0.2
```

后续版本先提交代码、保持工作区干净，再由 npm 更新版本并创建版本提交及标签：

```sh
npm version patch
git push origin HEAD --follow-tags
```

仓库尚未配置或 Actions 尚未运行时，本地生成 exe 不代表 GitHub Release 已发布。Mac 上生成 Windows exe 也不代表已在 Windows 实机运行；工作流中的 Windows 自检用于补充验证。

## 本地与隐私

- 模型、JavaScript 和 WASM 存放在 `public/`，运行时从当前本地服务读取。依赖准备完成后可以断网使用。
- 摄像头帧在本机 Worker 中推理，应用没有上传图片、遥测或后端服务。
- 开发/预览服务仅监听 `127.0.0.1`，不会默认暴露给局域网。
- 首次资源准备下载来源是 npm 官方仓库和 Google 的公开模型存储；模型来源及本地校验值记录在 `public/models/manifest.json`。

## 验证与构建

```sh
npm test
npm run build
npm run preview
```

另有模型自检页面：<http://127.0.0.1:5173/model-check.html>。点击运行可初始化真实模型并推理一张空白帧，无需申请摄像头权限。它验证本地资源和推理链路，不能替代真人手势测试。

- 自动测试涵盖分段笔画、命中、拖动、丢手释放、捏合滞回、防抖、异常点、绘图上限、摄像头取消与清理和断流检测，以及浪漫手势的一次触发、阶段切换、延迟帧、星花上限和正方形坐标映射。
- 浪漫手势使用合成关键点验证；按钮流程通过不等于真人识别准确率通过，需在实际摄像头、光线和手势姿态下试用。
- 内置浏览器已触发 PNG 导出，但未确认下载落盘；如未收到文件，请在 Chrome / Edge 中保存。
- 页面 FPS 是画布渲染帧率；ms 是最近一次模型推理耗时，不等于摄像头到显示的端到端延迟。
- 单目模型不能保证精确空间测量。快速运动、逆光、手指遮挡、距离过远以及设备负载都会降低准确性。当前只跟踪一只手。
- 笔迹有 10,000 点上限，超出后逐步淘汰最旧笔迹，以免长时间使用内存持续增长。
- 此版本没有旋转、双手缩放、抛掷惯性或外部实物控制。

## 技术与来源

原生 JavaScript / Canvas 2D、Vite、MediaPipe Hand Landmarker 0.10.32。采用普通 Worker 兼容 MediaPipe 的 `importScripts` WASM 加载器，CPU 推理和画布渲染分开执行，每次最多一帧推理。

MediaPipe：<https://developers.google.com/edge/mediapipe/solutions/vision/hand_landmarker/web_js>（库许可证 Apache-2.0，详见第三方项目）。

参考作品：<https://www.douyin.com/video/7690838038885142649>。本项目没有使用作者源代码或下载作者素材，也不声称与原视频的技术实现相同。
